API Quickstart & Code Examples

OmniGo exposes standard OpenAI endpoints. Point any coding tool (Claude Code, Cursor, Cline, OpenCode, Aider) directly to this gateway.

1 cURL: Chat Completions (Combo or Direct Model) 
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ak-<your-key>" \
  -d '{
    "model": "auto",
    "messages": [{"role": "user", "content": "Hello from OmniGo gateway!"}],
    "stream": true
  }'
2 cURL: List Aggregated Model Catalog 
curl http://localhost:8080/v1/models \
  -H "Authorization: Bearer ak-<your-key>"
3 Python (openai SDK) 
from openai import OpenAI
client = OpenAI(base_url="http://localhost:8080/v1", api_key="ak-...")
response = client.chat.completions.create(
    model="auto",  # or direct: "agy/gemini-3.7-flash"
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.choices[0].message.content)
